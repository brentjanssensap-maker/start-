## 2. Selectors lezen

Welke elementen raakt elke selector? Eén zin per selector.

- a. `header nav ul li a`: sellecteer alle a ellementen binnen een li binnen een ul binnen een nav binnen een header

- c. `.uren li:nth-child(3)`: sellecteerd het 3de ellement binnen de klass uren
- d. `h2 ~ p`:  selekteert alle p ellementen van tittel 2 
- e. `.rassen li:first-child`: sellekteert het eerste ellement van i
